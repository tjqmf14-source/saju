# 내사주 최신 Android 빌드

- 버전: **2.4.0**
- 브랜치: **main**
- 패키지: `kr.naesaju.personal`
- APK 아티팩트 이름: **Naesaju-Android-Debug**
- 설치 파일명: `Naesaju-2.4.0-debug.apk`

## 최신 반영 내용

- 화이트톤 중심의 간결한 웹·Android UI로 리빌딩
- 사용자 화면에서 명리학 전문용어와 계산 원자료를 숨기고 생활 언어 조언 중심으로 재구성
- 반복 문장을 자동 정리하는 쉬운말 표시 계층 추가
- Android 상태바·내비게이션바·WebView 배경을 밝은 테마로 통일

- 사주팔자 운세박사 기준 샘플과 사주팔자·십성·대운 교차검증
- 일간 표기의 `일간` / `비견` 차이를 동치로 처리
- 원국 × 월운의 합·충·형·파·해 관계를 월별 해석 근거에 포함
- 1~12월의 핵심·행동·주의 조언을 각각 중복 없이 생성
- 사용자 조언 문장을 짧고 바로 읽히도록 축약
- 기존 대운·세운·월운·진태양시·절기 계산 유지
- Android 앱과 웹 소스 동일 버전 유지

## 검증 기준

- Node 단위/계산/개인정보 테스트
- Chromium 데스크톱·태블릿·모바일 시각 QA
- Android Lint
- Android Debug APK 빌드 및 산출물 확인

이 문서는 최신 모바일 빌드 상태를 식별하기 위한 저장소 기준 파일입니다.
