# 내사주 v3 정밀 계산·딥네이비·타로 설계

## 목표

기존 오프라인 사주 사이트를 세 방향으로 업그레이드한다.

1. 계산 정확도를 높인다.
2. 해석을 유료 리포트 수준으로 자세하게 만든다.
3. 딥네이비 기반의 현대적 점술 UI와 오프라인 타로 기능을 추가한다.

## 계산 정확도

기존 `manseryeok@2.0.0`의 KASI 기반 음력·절기·일진 계산을 그대로 사용한다. 연주 입춘, 월주 절입, 음력 윤달, 대운 계산은 패키지 결과를 신뢰하고 앱에서 임의 재계산하지 않는다.

### 정밀 시간 보정

기본 입력 화면은 간편하게 유지한다. `정밀 계산`을 기본 ON으로 두고 다음을 적용한다.

- 기본 경도: 대한민국 평균 127.5°E
- 균시차 보정: ON
- 과거 표준시/DST 보정: ON
- 자시 일 경계: 자정(00:00) 기준

`정밀 설정`을 펼치면 사용자가 다음을 바꿀 수 있다.

- 출생 지역: 한국 평균, 서울, 부산, 대구, 인천, 광주, 대전, 울산, 제주, 세종
- 진태양시 보정 ON/OFF
- 자시 관법: 자정 / 자시 환일 / 분할자시

출생지는 서버에 전송하거나 저장하지 않는다.

### 계산 근거 표시

결과 상단에 계산 기준을 보여준다.

- 양력/음력 변환 기준
- 적용 경도
- 균시차 적용 여부
- 역사적 표준시/DST 적용 여부
- 자시 관법

진태양시와 자시 관법은 명리 학파에 따라 달라질 수 있음을 명시한다.

## 상세 해석

짧은 카드 문장 위주 구조를 버리고, `원인 → 실제 성향 → 장점 → 주의점 → 활용법` 순서의 장문 리포트로 확장한다.

상세 섹션:

- 타고난 기질
- 겉으로 보이는 모습과 내면
- 강점과 잠재력
- 일·직업·재능
- 돈과 현실 감각
- 연애와 가까운 관계
- 인간관계와 사회적 역할
- 스트레스 패턴과 회복 방식
- 올해의 핵심 흐름
- 월별 흐름
- 대운의 큰 전환점

해석 근거는 일간, 오행 분포, 십성 그룹, 지지 관계, 세운/월운, 대운을 조합한다. 단정적 예언 대신 경향과 활용법으로 표현한다.

## 사주 기반 MBTI

기존 기능을 유지하되 결과 유형만 보여주지 않는다.

- 4축 비율
- 각 축에 영향을 준 오행·십성
- 실제 생활에서 드러나는 방식
- 강점과 과사용 시 주의점

정식 MBTI 검사를 대체하지 않는다는 문구를 유지한다.

## 디자인

메인 톤은 딥네이비다.

- 배경: `#070B18` / `#0C1226`
- 카드: `#111A34` / 반투명 네이비
- 주요 텍스트: 아이보리 `#F6F0E5`
- 보조 텍스트: 쿨그레이 `#A7AEC4`
- 포인트 1: 라벤더 `#8F82FF`
- 포인트 2: 쥬얼 틸 `#4ED8C8`
- 포인트 3: 옅은 골드 `#D9B97B`

시각 방향은 `Modern Editorial Mystic`으로 한다. 둥근 파스텔 카드 반복을 줄이고, 큰 타이포그래피, 넓은 여백, 얇은 라인, 별자리/달/궤도 그래픽, 반투명 글래스 패널을 제한적으로 사용한다.

전통 수묵 일러스트를 전면에 크게 쓰지 않고, 한국적인 느낌은 얇은 먹선·인장·한자 표식 정도로 절제한다.

## 타로

오프라인 메이저 아르카나 22장으로 시작한다.

제공 스프레드:

- 오늘의 카드 1장
- 질문 타로 3장: 현재 / 장애물 / 조언
- 연애 타로 3장: 나 / 상대 / 관계 흐름
- 일·재물 타로 3장: 현재 / 기회 / 주의점

카드 선택은 브라우저 `crypto.getRandomValues()` 기반으로 셔플한다. 질문 텍스트와 결과는 서버로 보내거나 저장하지 않는다.

각 카드 데이터:

- 번호
- 한글/영문 이름
- 핵심 키워드
- 정방향 해석
- 역방향 해석
- 연애 해석
- 일·재물 해석

카드 앞면은 저작권 이미지가 아닌 자체 CSS/기호 기반 디자인으로 만든다.

## 개인정보

- fetch/XHR 전송 없음
- localStorage/cookie 사용 없음
- 생년월일·시간·출생지·질문 텍스트는 메모리에만 존재
- 페이지 새로고침 시 입력/타로 질문 기록은 영구 저장되지 않음

## 테스트

- 기존 달력/절기/사주/MBTI 테스트 유지
- 정밀 모드에서 `trueSolarTime` 옵션이 엔진에 전달되는지 검증
- 1990-05-15 07:05 서울 예제에서 정밀 보정 시 시지가 진→묘로 변경되는지 검증
- 정밀 설정 OFF 시 기존 KST 결과를 유지하는지 검증
- 자시 관법 옵션 전달 검증
- 상세 해석 함수가 모든 필수 섹션을 생성하는지 검증
- 타로가 22장 중 중복 없이 1장/3장을 반환하는지 검증
- 타로 정·역방향이 결정적으로 유효한 구조를 반환하는지 검증
- 네트워크/스토리지 금지 검사 유지
- 프로덕션 빌드 성공
