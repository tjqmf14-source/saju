# 내사주DB v2 설계

## 목표

`내사주DB`를 개인 고정값 데모에서 **1900~2100년 범용 오프라인 사주 프로그램**으로 전환한다. 정확한 만세력 계산을 최우선으로 하고, 계산 결과를 바탕으로 한 **사주 기반 성향 MBTI**를 대표 기능으로 제공한다.

## 핵심 원칙

- 모든 계산은 브라우저 내부에서 수행한다.
- CDN, 외부 API, 서버 저장, 회원가입, 분석 로그를 사용하지 않는다.
- 입력값은 메모리에서만 사용하고 자동 저장하지 않는다.
- 양력/음력, 윤달, 생년월일, 출생시간, 성별을 입력받는다.
- 지원 범위는 1900-01-31부터 2100-12-31까지로 제한한다.
- 계산 사실과 해석을 분리한다.
- 임의의 행운 점수·랜덤 점수는 제거한다.
- `사주 기반 성향 MBTI`는 정식 MBTI 심리검사가 아니라 사주 요소를 4개 축으로 번역한 참고 지표임을 명시한다.

## 아키텍처

정적 HTML/CSS + ES Modules 구조를 유지한다. 런타임 의존성은 0개다.

- `src/calendar.js`: 양력↔음력 변환, 윤달 검증
- `src/solar-terms.js`: 태양 황경 기반 24절기 시각 계산
- `src/saju-engine.js`: 연주·월주·일주·시주, 십성, 오행, 합충형파해, 대운/세운/월운
- `src/mbti.js`: 사주 기반 MBTI 4축 계산과 근거 생성
- `src/interpretation.js`: 계산 결과를 한국어 생활 언어로 변환
- `src/app.js`: 입력 검증, 화면 렌더링, 상태 관리
- `src/data.js`: 천간·지지·지장간·관계·해석 상수
- `tests/*.test.js`: Node 내장 테스트 러너 기반 회귀 테스트

## 달력 변환

1900~2100 음력 연도 비트 테이블을 앱 내부에 포함한다. 기준일은 `1900-01-31 = 음력 1900-01-01`이다. 양력→음력과 음력→양력은 동일 테이블을 역방향으로 사용해 왕복 검증 가능하게 한다.

윤달은 해당 연도에 실제 윤달이 있을 때만 허용한다. 지원 범위를 벗어난 입력은 계산하지 않고 오류 메시지를 표시한다.

## 절기 계산

연주·월주 경계를 단순 고정 날짜로 처리하지 않는다. 태양의 겉보기 황경을 계산하고 뉴턴 반복으로 각 절기의 UTC 시각을 찾은 뒤 한국 표준시(UTC+9)로 비교한다.

- 연주 경계: 입춘(315°)
- 월주 경계: 입춘 315°, 경칩 345°, 청명 15°, 입하 45°, 망종 75°, 소서 105°, 입추 135°, 백로 165°, 한로 195°, 입동 225°, 대설 255°, 소한 285°

절기 경계 직전/직후 입력에서도 같은 계산 함수를 사용한다.

## 사주 원국

- 연주: 입춘 경계 기준
- 월주: 12절(節) 경계 기준, 오호둔으로 월간 산출
- 일주: 율리우스 일수 기반 60갑자 인덱스
- 시주: 2시간 단위 지지와 오자둔으로 시간 산출
- 날짜 변경 기준은 민간 사용성이 높은 **현지 자정 기준**으로 통일한다. 23시 자시를 다음 날로 넘기는 별도 학파 규칙은 적용하지 않고 UI에 기준을 표시한다.

## 십성·오행

천간과 지장간을 대상으로 십성을 계산한다. 오행 분포는 지지 자체와 지장간을 중복 계수하지 않고 다음 가중치를 사용한다.

- 천간: 각 1.0
- 지장간 본기/중기/여기: 지장간 개수에 따라 합계 1.0이 되도록 1개=1.0, 2개=0.7/0.3, 3개=0.6/0.25/0.15

오행 결과는 상대 분포로 표시하고, 이를 절대적인 길흉 점수로 바꾸지 않는다.

## 구조 관계

지지 관계는 최소한 다음을 탐지한다.

- 육합
- 육충
- 삼합(완성 조합)
- 형
- 파
- 해

탐지 결과는 사실 영역에 관계명과 대상 지지를 보여주고, 해석 영역에서는 과장된 단정 대신 성향·환경 변화의 참고 신호로 설명한다.

## 대운

순행/역행은 성별과 연간 음양을 조합한다.

- 남 + 양년 / 여 + 음년 = 순행
- 남 + 음년 / 여 + 양년 = 역행

기산은 출생 시각에서 순행이면 다음 절(節), 역행이면 이전 절까지의 실제 시간 차이를 사용한다. `3일 = 1년` 규칙으로 시작 나이를 소수점으로 계산하고, 표시할 때 년·개월 수준으로 환산한다. 첫 대운은 월주에서 진행 방향으로 한 단계 이동한 간지부터 시작한다.

## 세운·월운

세운 연주는 각 해 입춘 기준으로 계산한다. 월운은 해당 연도의 실제 절입 시각을 사용해 월주를 생성한다. 기존의 임의 수치 점수는 제거하고, 일간과의 십성 관계·원국 지지와의 합충 관계를 요약한다.

## 사주 기반 성향 MBTI

정식 MBTI 검사를 대체하지 않는다. 원국의 오행 분포, 십성 분포, 음양 비율을 4축으로 변환한다.

### E / I

- E: 식상, 비겁, 화·목의 외향 표현 성향
- I: 인성, 관성, 수·금의 내향 관찰 성향

### S / N

- S: 재성, 관성, 토·금의 현실·구조 성향
- N: 인성, 식상, 목·수의 개념·가능성 성향

### T / F

- T: 관성, 재성, 금·수의 기준·분석 성향
- F: 인성, 비겁, 목·화의 관계·가치 성향

### J / P

- J: 관성, 재성, 토·금의 계획·완결 성향
- P: 식상, 비겁, 목·수의 탐색·유연 성향

각 축은 양쪽 점수를 모두 계산해 0~100 비율로 정규화한다. 결과 유형만 보여주지 않고 각 축의 비율과 기여 요인을 함께 표시한다. `사주 기반 성향 MBTI · 비공식 참고`라는 라벨을 항상 노출한다.

## UI

첫 화면은 입력 폼과 개인정보 안내를 중심으로 구성한다.

입력:
- 달력 종류: 양력 / 음력
- 음력 선택 시 윤달 체크
- 생년월일
- 출생시간
- 성별

결과 순서:
1. 핵심 요약
2. 사주 기반 성향 MBTI
3. 사주 원국 4주
4. 오행·십성
5. 합충형파해 구조
6. 대운
7. 세운
8. 월운
9. 해석 및 행동 참고

모바일 1열, 태블릿 2열, 데스크톱 다열 반응형으로 구성한다.

## 개인정보

화면 상단에 `브라우저 내 계산 · 서버 전송 없음 · 자동 저장 없음`을 표시한다. localStorage, cookies, fetch/XHR를 사용하지 않는다.

## 제거 대상

- 개인 고정 출생정보
- 랜덤/의사랜덤 운세 점수
- 고정 날짜 절기 계산
- 근사 대운 시작 나이
- 현재 사주 앱과 무관한 `comfyui-mcp-server.mjs`

## 테스트 기준

- 1900-01-31 ↔ 음력 1900-01-01
- 2024-02-10 ↔ 음력 2024-01-01
- 2023-03-22 ↔ 음력 2023 윤2월 1일
- 양력→음력→양력 왕복 일치
- 윤달 유효성 검증
- 입춘 전후 연주 변경
- 망종 전후 월주 변경
- 1987-06-14의 연주가 丁卯, 월주가 丙午
- 시주 23:00~00:59 자시 처리
- 대운 방향 규칙
- MBTI 축 값이 0~100 범위이며 동일 입력에 결정적으로 동일 결과 반환
- 외부 네트워크 호출 코드가 없음
