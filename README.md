# 내사주DB v2

한국 만세력 기반의 **오프라인 사주 원국 + 사주 기반 성향 MBTI** 웹앱입니다.

## 핵심 특징

- 1900~2100년 양력/음력 입력
- 음력 윤달 지원
- 출생시간·성별 기반 사주 원국 계산
- 연주·월주·일주·시주, 십성, 오행, 공망, 대운
- 합·충·형·파·해 구조 표시
- 세운·월운 흐름
- 오행·십성 분포를 이용한 `사주 기반 성향 MBTI`
- 모바일/태블릿/데스크톱 반응형 UI

## 정확도 기준

사주 원국과 달력 계산은 `manseryeok 2.0.0`을 사용합니다. 이 라이브러리는 한국천문연구원(KASI) 기준 한국 음양력 데이터와 정밀 절기 데이터를 기반으로 하며, 중국식 범용 음력 테이블에서 발생할 수 있는 한국 달력 차이를 피합니다.

이 앱은 간편형이므로 다음 기준을 사용합니다.

- 시간대: 한국 표준시(KST, UTC+9)
- 일진 경계: 자정(00:00)
- 출생지 입력 없음
- 진태양시/경도 보정 없음

출생지가 절기 또는 시주 경계에 매우 가까운 경우에는 출생지 보정을 사용하는 전문 만세력과 결과가 달라질 수 있습니다.

## 사주 기반 성향 MBTI

정식 MBTI 심리검사가 아닙니다. 원국의 오행과 십성 분포를 다음 4개 성향 축에 구조적으로 매핑한 **비공식 자기이해 지표**입니다.

- E / I: 표현·자기주도 ↔ 관찰·규범
- S / N: 현실·구조 ↔ 개념·가능성
- T / F: 기준·분석 ↔ 관계·가치
- J / P: 계획·완결 ↔ 탐색·유연

유형 글자만 보여주지 않고 각 축의 비율과 산출 근거도 함께 표시합니다.

## 개인정보 처리 방식

출생 정보는 브라우저 메모리에서만 계산합니다.

- 서버 전송 없음
- 회원가입 없음
- 쿠키 없음
- `localStorage` / `sessionStorage` 저장 없음
- 분석/추적 로그 없음
- 외부 API 호출 없음

`npm run check:network`로 앱 소스의 네트워크 전송 및 브라우저 영구 저장 API 사용 여부를 검사합니다.

## 개발 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

테스트와 개인정보 정책 검증:

```bash
npm run check
```
